# Эмулятор командной оболочки ОС (вариант 25)

## 1. Общее описание
Эмулятор командной строки UNIX-подобной ОС с виртуальной
файловой системой (VFS). Реализованы все этапы 1-5:
интерактивный REPL, настройка через параметры командной
строки, стартовые скрипты, загрузка VFS из JSON в память,
основные команды работы с VFS, флаги команды ls и команда
cp, изменяющая состояние VFS только в памяти.

## 2. Описание всех функций и настроек
Команды эмулятора:
- `ls [флаги] [путь]` — список содержимого каталога; флаги:
  `-a` показать скрытые имена (начинаются с точки), `-l`
  длинный формат (тип, размер, имя), `-h` человекочитаемые
  размеры; флаги сочетаются (`-la`, `-lh`); без аргумента —
  текущий каталог
- `cd [путь]` — смена текущего каталога; без аргумента —
  возврат в корень
- `du [путь]` — размер поддерева в байтах; без аргумента —
  текущий каталог
- `pwd` — печать текущего пути
- `whoami` — печать имени пользователя виртуальной системы
- `tree` — печать дерева VFS
- `cp <источник> <приёмник>` — копирование файла или каталога
  со всем содержимым; изменения происходят только в памяти,
  JSON-файл на диске не изменяется
- `exit` — завершение работы эмулятора

Пути: абсолютные (начинаются с '/') и относительные,
поддерживаются элементы '.' и '..'.

Обработка ошибок: неизвестная команда, несуществующий путь,
переход в файл, отсутствие загруженной VFS, отсутствие файла
VFS или скрипта, некорректный JSON, неверное число аргументов
cp, копирование каталога в самого себя, перезапись файла
каталогом.

Параметры командной строки:
- `--vfs-path` — путь к JSON-файлу VFS (по умолчанию None)
- `--script` — путь к стартовому скрипту (по умолчанию None)

## 3. Команды для сборки и запуска тестов
Запуск эмулятора:
run.bat

Запуск тестов:
python -m pytest tests/

Проверка оформления:
python -m flake8 src tests --max-line-length=80

## 4. Примеры использования
Сессия с глубокой VFS:
Stariy> pwd
/
Stariy> cd home/user
Stariy> pwd
/home/user
Stariy> ls
docs
todo.txt
Stariy> du
17 bytes /home/user
Stariy> whoami
ded

Скрытые файлы и флаги ls:
Stariy> ls home/user
docs
todo.txt
Stariy> ls -a home/user
.profile
docs
todo.txt
Stariy> ls -l home/user
d 6B docs/
- 4B todo.txt

Копирование в памяти:
my_vfs> ls etc
config.cfg
my_vfs> cp etc/config.cfg etc/config.backup
my_vfs> ls etc
config.backup
config.cfg
my_vfs> cp home/user home/backup
my_vfs> ls home
backup
user

Обработка ошибок cp:
my_vfs> cp a.txt
Usage: cp <source> <destination>
my_vfs> cp home home/inner
Error: cannot copy directory into itself: home
