# Эмулятор командной оболочки ОС (вариант 25)

## 1. Общее описание
Эмулятор командной строки UNIX-подобной ОС с виртуальной
файловой системой (VFS). Реализованы этапы 1-3: интерактивный
REPL, настройка через параметры командной строки, стартовые
скрипты и загрузка VFS из JSON целиком в память.

## 2. Описание всех функций и настроек
Команды эмулятора:
- `ls` — заглушка: выводит имя команды и аргументы
- `cd` — заглушка: выводит имя команды и аргументы
- `tree` — выводит дерево загруженной VFS (только чтение)
- `exit` — завершение работы эмулятора
- неизвестная команда — сообщение об ошибке, работа продолжается

Параметры командной строки:
- `--vfs-path` — путь к JSON-файлу VFS (по умолчанию None)
- `--script` — путь к стартовому скрипту (по умолчанию None)

Формат VFS: JSON-файл с ключами vfs_name и root. Узлы бывают
двух типов: dir (с children) и file (с content в base64).
Все операции с VFS выполняются только в памяти, данные на
диске не изменяются.

## 3. Команды для сборки и запуска тестов
Запуск эмулятора:
run.bat

Запуск тестов:
python -m pytest tests/

Проверка оформления:
python -m flake8 src tests --max-line-length=80

## 4. Примеры использования
Интерактивный режим с загруженной VFS:
python -m src.main --vfs-path data/deep.json
my_vfs> tree
my_vfs/
home/
    user/
        docs/
            report.txt
        todo.txt
etc/
    config.cfg

Стартовый скрипт со всеми командами:
python -m src.main --vfs-path data/deep.json --script scripts/all_commands.sh

Обработка ошибок:
python -m src.main --vfs-path data/missing.json
Error: VFS file not found: data/missing.json
