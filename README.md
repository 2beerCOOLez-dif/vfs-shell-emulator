# Эмулятор командной оболочки ОС (вариант 25)

## 1. Общее описание
Эмулятор командной строки UNIX-подобной ОС с виртуальной
файловой системой (VFS). Реализованы этапы 1 и 2: интерактивный
REPL-прототип с командами-заглушками и настройка через
параметры командной строки с выполнением стартовых скриптов.

## 2. Описание всех функций и настроек
Команды эмулятора:
- `ls` — заглушка: выводит имя команды и аргументы
- `cd` — заглушка: выводит имя команды и аргументы
- `exit` — завершение работы эмулятора
- неизвестная команда — сообщение об ошибке, работа продолжается

Параметры командной строки:
- `--vfs-path` — путь к файлу VFS (по умолчанию None)
- `--script` — путь к стартовому скрипту (по умолчанию None)

Стартовый скрипт: текстовый файл с командами эмулятора,
комментарии начинаются с символа `#`. При выполнении выводится
и ввод, и вывод, имитируя диалог с пользователем.

## 3. Команды для сборки и запуска тестов
Запуск эмулятора:
run.bat

Запуск тестов:
python -m pytest tests/

Проверка оформления:
python -m flake8 src tests --max-line-length=80

## 4. Примеры использования
Интерактивный режим:
my_vfs> ls folder1
ls called with args: folder1
my_vfs> exit
Goodbye!

Режим стартового скрипта:
python -m src.main --script scripts/example.sh

Обработка ошибки отсутствия скрипта:
python -m src.main --script missing.sh
Error: Script file not found: missing.sh
